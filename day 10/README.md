## 📅 Day 10 - My Applications Feature

### 🔹 Objective
Display all jobs applied by a student.

### 🔹 Features Implemented
- Fetch applications using Apex
- Display job name, company, status, and application date
- Prevent duplicate applications

### 🔹 Technologies Used
- Apex
- Lightning Web Components (LWC)
- Salesforce Objects
