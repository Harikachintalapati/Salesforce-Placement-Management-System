# 📅 Day - LWC (Lightning Web Component)

## 🔹 Objective
Build a basic UI using Lightning Web Components (LWC) for Placement Management System.

---

## 🔹 What I Built

- Created a Placement Portal UI
- Displayed student details (Name, Roll No, Department)
- Added dynamic message using button
- Implemented status change using JavaScript
- Built a simple dashboard with static data

---

## 🔹 Features

- Welcome message display
- Student information display
- Button click functionality
- Status change (Not Applied → Applied)
- Dashboard with:
  - Number of Companies
  - Number of Jobs
  - Applications Submitted

---

## 🔹 Technologies Used

- Lightning Web Components (LWC)
- HTML
- JavaScript
- Salesforce Lightning App Builder

---

## 🔹 LWC Files

- HTML → UI Design  
- JavaScript → Logic & Events  
- Meta XML → Component visibility in App Builder
