# Day 4 - Lightning Web Components (LWC)

## Project Name
Placement Portal

## Objective
To learn the basics of Lightning Web Components by creating a simple Placement Portal application.

## Features
- Display Welcome to Vishnu Placement Portal
- Display Student Name
- Display Roll Number
- Display Department
- Show Welcome Message button
- Apply button
- Status changes from Not Applied to Applied
- Display Number of Companies, Jobs, and Applications

## Files Used
- placementHome.html
- placementHome.js
- placementHome.js-meta.xml

## Technologies Used
- Salesforce
- Lightning Web Components (LWC)
- HTML
- JavaScript

## What I Learned
- Creating an LWC
- Data Binding
- Event Handling
- Deploying components in Lightning App Builder
- Updating values dynamically using JavaScript
