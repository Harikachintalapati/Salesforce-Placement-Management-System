# Salesforce Placement Management System

## 📌 Project Overview
This project is a Salesforce-based Placement Management System designed to help students view job opportunities, apply for jobs, and track their applications.

---

## 🚀 Features Implemented

### 📅 Day 9 - Job Application Feature

- View Eligible Jobs
- View Job Details (Popup)
- Apply for Jobs
- View Applied Jobs (My Applications)
- Backend integration with Application Object

---

## 🛠️ Technologies Used

- Salesforce LWC (Lightning Web Components)
- Apex Classes
- SOQL
- Lightning App Builder
